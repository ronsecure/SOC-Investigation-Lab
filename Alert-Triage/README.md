# SOC Alert Triage

This section documents practical exercises focused on reviewing security alerts, assessing suspicious activity, and recording investigation findings.

## Topics

- Initial alert assessment
- Identifying suspicious user activity
- Reviewing authentication failures
- Distinguishing benign and suspicious events
- Assessing alert severity and priority
- Escalation decisions

## Triage Approach

**Understand → Investigate → Decide → Document**

Each exercise focuses on reviewing available evidence, identifying relevant activity, determining whether further investigation is required, and recording clear findings.

## Investigation Outcomes

- Benign — No suspicious activity identified.
- Investigate — Additional evidence is required.
- Escalate — Findings require further security investigation.
